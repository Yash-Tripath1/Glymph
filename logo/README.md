# Glymph Studio — logo

The mark: a chunky geometric **G** with a **lightning bolt slashing through it**.

| file | what it is | use it on |
|---|---|---|
| `glymph-logo.svg` | white G + red bolt, transparent bg | **primary**, dark backgrounds |
| `glymph-logo-light.svg` | black G + red bolt (white punch-out) | light backgrounds |
| `glymph-logo-mono.svg` | white G, bolt knocked out in black | one-colour / print on dark |
| `glymph-logo-appicon.svg` | mark on solid black | avatars, favicons, app icon |
| `glymph-logo-white.png` | 1024² transparent, white + red | dark bg |
| `glymph-logo-black.png` | 1024² transparent, black + red | light bg |
| `glymph-logo-mono.png` | 1024² transparent, mono | dark bg |
| `glymph-logo-appicon.png` | 1024², black bg | socials / app icon |
| `favicon-512.png` | 512² | favicon |
| `glymph-logo-sheet.png` | preview of all variants | — |

**Colours** — red `#FF3B2F`, blue `#2D5BFF`, black `#000000`, white `#FFFFFF`.

Everything is 200×200 viewBox geometry, no strokes on the G (filled rects), so it
renders identically in every browser, Figma, Illustrator and rasteriser.
